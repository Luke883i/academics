# Historical academic archive path

`academic-lineage/` is a historical directory name retained to preserve Git history and existing links.

The PDF artifacts in this directory document **Gianluca Conte's academic record**. The directory name must not be interpreted as lineage of the ROA Research Programme.

In particular, co-location, chronology and common authorship do not establish that the theses formally derive, validate, anticipate or provide evidence for ROA.

Canonical author/archive metadata is maintained in [`../AUTHOR.json`](../AUTHOR.json). Canonical ROA programme identity and topology are maintained separately in [`../PROGRAMME.json`](../PROGRAMME.json).
