# ROA Research Programme

**Computational Epistemics, Semantic Architectures & Governable AI Systems**

This repository is the coordination hub and academic-lineage register for the ROA Research Programme. It centralizes programme identity, repository roles and cross-repository relation semantics without replacing any repository's local runtime, release, evidence or governance authority.

## Research question

How can AI systems compute, represent, persist and govern semantic and epistemic state within declared horizons while keeping evidence, inference, authority, decision, execution and observed-world truth distinguishable and reconstructable?

## Programme invariants

Across the programme, repository-specific implementations preserve variants of the same anti-laundering discipline:

> representation ≠ reality · model output ≠ evidence · evidence ≠ permission · permission ≠ decision · decision ≠ execution · execution ≠ observed-world truth · receipt ≠ external validation · implementation ≠ scientific proof

Current state always resolves back to each repository's own authority surfaces.
