# ROA Research Programme

**Computational Epistemics, Semantic Architectures & Governable AI Systems**

The programme studies how bounded human–AI observers can construct, transform, persist and use epistemic state without silently converting representation into reality, model output into evidence, evidence into authority, or execution into observed-world truth.

`academics` is the master coordination hub: it owns programme identity, membership, repository roles, cross-repository relations, academic lineage and shared claim boundaries. It does **not** replace repository-local runtime, release, evidence or governance authority. [`ROA`](https://github.com/Luke883i/ROA) owns the theoretical framework.

## Research question

How can AI systems compute, represent, persist and govern semantic and epistemic state within declared horizons while keeping evidence, inference, authority, decision, execution and observed-world truth distinguishable and reconstructable?

## Research architecture

```text
academic lineage ──> ROA theory ──> implementation / agent witnesses
                                      │
                                      ├─ A-OSP
                                      └─ iKant ──> iKant_LE

programme stress surfaces: ICTC · Juriscribe · Teddy
legacy engineering lineage: aosp ──> A-OSP
```

ROA is the theoretical anchor, not the programme itself. The other repositories materialize, align with, compress, apply, stress or historically precede parts of the programme without thereby validating the theory.

## Epistemic boundary

Across the programme, repository-specific implementations preserve variants of one shared anti-laundering discipline:

> representation ≠ reality · model output ≠ evidence · evidence ≠ permission · permission ≠ decision · decision ≠ execution · execution ≠ observed-world truth · receipt ≠ external validation · implementation ≠ scientific proof

Programme membership likewise does not establish formal derivation, ROA conformance, empirical validation or production readiness.
