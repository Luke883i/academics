# Historical snapshot

The programme hub was reorganized from the public Git revision
[`12c1526041815e5dfc5344d7200fd0ff74e61565`](https://github.com/Luke883i/academics/tree/12c1526041815e5dfc5344d7200fd0ff74e61565).

This baseline preserves the original `academic-lineage/` PDF paths,
`AUTHOR.json`, earlier programme descriptions, legacy workflows, scripts,
and synthetic evidence receipts.

The four original thesis PDFs are carried forward under `theses/`
without changing their Git blob identities. The new programme registry
records the original blob SHA of each PDF.

Historical receipts belong to the revision and assumptions they tested;
they do not attest to later versions, deployed products, scientific
validity, or the professional credentials of the author.

For active product functionality, evidence, releases and tests, consult
each project's own repository.
